# lumen AI 学习 / 教学辅助工具 · 设计稿

> 定位：本地优先（local-first）的单机工具，面向学生与教师，提升学习与教学效率。
> 状态：概念设计 v0.1（未实现）

---

## 1. 产品定位与原则

| 项 | 说明 |
| --- | --- |
| 形态 | 桌面应用（本地运行），非网站、非 SaaS，单机单用户 |
| 用户 | 学生（自学、备考）、教师（备课、出题、答疑）——均为本地使用者 |
| 核心价值 | 把"教材"变成可查询、可练习、可测评、可讲解的私有知识库 |
| 隐私 | 教材与作答数据留在本地；默认调用云端 API（用户自带 Key），也支持本地模型离线运行 |

**设计原则**

1. **本地优先**：数据在本地 SQLite/文件系统；离线可用核心链路。
2. **教材即知识库**：一切 AI 能力（出题、答疑、总结、阅卷）都以教材内容为依据，可溯源到"第几章第几页"。
3. **AI 任务即工作流**：每个智能能力都是"选范围 → 选模型 → 生成 → 人工校对 → 存档"的统一流程。
4. **可干预**：AI 产出物全部可编辑、可保存、可导出，不追求全自动。

## 2. 核心概念模型（领域模型）

```
Course 课程
 ├── 元信息：名称、科目、封面、创建者、学期、描述
 ├── Textbook 教材（1..n）
 │    ├── 源文件（PDF / DOCX / Markdown / TXT / EPUB）
 │    ├── 解析状态、页数、字数
 │    └── Chapter 章节（树形：章 → 节 → 小节，1..n）
 │         ├── 标题、层级、页码范围、原文内容（段落块）
 │         └── KnowledgePoint 知识点（可选，自动抽取）
 ├── Exercise 习题 / Paper 试卷
 │    ├── 范围：章节 / 教材 / 全部教材；题型；难度；数量
 │    ├── 题目、选项、参考答案、解析、来源引用（章节+页码）
 │    └── Attempt 作答记录 → AI 阅卷结果（得分、批注）
 ├── Summary 知识总结（章节级笔记，可多版本）
 ├── LessonPlan 教案（面向教师）
 └── Session 答疑会话（学生 ↔ AI 教师，带引用）
```

**全局资源**

- `Model` 模型配置：名称、提供商（OpenAI 兼容 / Ollama / LM Studio / Claude 等）、API 地址、Key（加密存储）、上下文长度、能力标签（text / vision / long-context）、是否默认。
- `PromptTemplate` 提示词模板：每个任务一个，可编辑。
- `AITask` 任务记录：类型、状态、耗时、token 用量、所用模型——便于成本审计与复跑。

## 3. 功能模块设计

### 3.1 课程管理
- 创建/编辑/归档课程；课程内可导入多本教材（同一课程的不同参考书）。
- 课程视图：左侧教材/章节树，右侧内容区。

### 3.2 教材导入与拆分
- **导入**：以 PDF 为主，同时支持 DOCX / MD / TXT / EPUB；扫描版 PDF（图片型）走 OCR（Tesseract / PaddleOCR，中文友好），作为可选步骤；大文件异步解析，进度条 + 断点续传式重试。
- **拆分**：
  - 首选依据文档自身结构（PDF 书签、DOCX 标题样式、MD 标题）生成章节树；
  - 无结构时：按页码/字数阈值自动切分，再用 LLM 为每段生成标题；
  - 人工可拖拽调整、合并、改名、重新划界。
- **索引**：拆章后对每章做向量化（本地 embedding 模型），供答疑检索；同时提取关键词/知识点。

### 3.3 习题与测试卷
- **生成范围**：指定章节 / 整本教材 / 课程全部教材；可多选交集。
- **参数**：题型（单选/多选/判断/填空/简答/计算/论述）、数量、难度梯度、是否配解析、是否配参考答案。
- **审校**：生成结果进入"草稿箱"，可编辑、删除、重新生成单题、标记题目质量。
- **测试卷模式**：设定时长、分数分布、题序随机、打乱选项；导出 PDF 试卷 + 单独导出答案卷。
- **作答与 AI 阅卷**：
  - 客观题：自动判分。
  - 主观题：应用内文字作答，AI 按"参考答案 + 评分细则"给分，输出得分点逐条点评、扣分原因、改进建议。
  - 纸笔作答：测验可导出 PDF 试卷打印作答，之后在应用内手动录入答案，再走同一阅卷流程。
  - 输出成绩单：得分、用时、知识点掌握度雷达图（按章节）。

### 3.4 知识总结（章节笔记）
- 按章节生成：知识框架（大纲）、核心概念定义、公式/定理清单、易错点、思维导图（文本版/可导出 Markdown + Mermaid）。
- 支持"总结 → 生成测验题"一键联动。

### 3.5 教师答疑（AI 教师）
- 对话式，强制 **RAG**：先从选定范围（本章节/本教材/全课程）检索相关段落，再作答，答案必须带引用（教材名、章节、页码/段落号）。
- 可选模式：直接给答案 / 苏格拉底式引导（先提示不直接给）/ 批改学生思路。
- 对话可收藏为"答疑卡片"存入笔记。

### 3.6 教案生成（教师）
- 输入：章节、教学目标、课时长度、学生学情（可选）、教学法偏好。
- 输出：教学目标、重难点、教学过程（导入/讲授/练习/小结）、课堂提问、随堂测题、作业布置。
- 教案与题库打通：随堂测题直接从题库挑选。

### 3.7 模型管理
- 默认可调用云端 API（用户自带 Key），同时保留本地模型（Ollama / LM Studio）选项以支持离线。
- 可视化增删改模型：测试连通性、测上下文长度、标注能力（文本/视觉/长文）。
- 任务级模型选择：每个 AI 任务下拉可选模型，并记住"该任务上次使用的模型"。
- 默认模型策略：按任务类型设默认（如答疑默认长上下文模型）。
- Key 本地加密（AES-256，主密钥放系统钥匙串）；用量统计（token/费用估算）。

## 4. 关键流程

### 4.1 教材导入流程
```
选择文件 → 格式检测 → 文本抽取（PDF 需 OCR 可选）
 → 结构识别（书签/标题样式）
   ├─ 成功 → 生成章节树 → 人工确认
   └─ 失败 → 自动切分 + LLM 拟标题 → 人工确认
 → 分段 → 向量化入库 → 完成（可查看每章字数/页码）
```

### 4.2 出题流程
```
选范围（章节/教材/全部）→ 设题型/数量/难度
 → 选模型 → 生成（流式输出，逐题出现）
 → 草稿箱审校（编辑/重生成/删除）
 → 发布：保存到题库 或 导出试卷(PDF) 或 直接测验
```

### 4.3 答题阅卷流程
```
开始测验（计时）→ 作答（客观题点选，主观题文本）
 → 提交 → 客观题即时判分
        → 主观题 AI 阅卷（并行逐题）→ 得分点点评
 → 成绩单 + 知识点掌握度分析 → 错题自动归入"错题本"
```

### 4.4 答疑流程
```
学生提问 → 检索（选定范围）→ 拼接原文片段 + 问题 → 模型作答
 → 引用标注（章节/页码）→ 学生追问（多轮，带历史）
```

## 5. 技术架构（建议）

```
┌──────────────────────────────────────────┐
│  桌面客户端 (Tauri / Electron + Web 前端)  │
├──────────────────────────────────────────┤
│  本地服务层 (Python FastAPI 或 Rust)      │
│  · 任务编排  · RAG 检索  · 文件解析       │
├──────────────────────────────────────────┤
│  存储层                                  │
│  · SQLite（课程/章节/题目/记录）          │
│  · 文件系统（教材原文、导出物）           │
│  · 向量库（Chroma / sqlite-vec，轻量本地） │
├──────────────────────────────────────────┤
│  模型层                                  │
│  · 本地：Ollama / llama.cpp（离线可用）   │
│  · 云端：OpenAI 兼容 API / Claude 等      │
└──────────────────────────────────────────┘
```

**选型要点**
- 客户端：Tauri（体积小）或 Electron（生态成熟）。
- PDF 解析：PyMuPDF / pdfplumber；扫描件 OCR：Tesseract 或 PaddleOCR（中文友好）。
- 向量检索：本地 Chroma 或 sqlite-vec，避免额外服务依赖。
- 导出：Markdown → PDF（WeasyPrint / Typst）。

## 8. 非功能需求与风险

| 风险 | 对策 |
| --- | --- |
| PDF 解析质量差（扫描件/公式） | OCR 可选；公式用 LaTeX 识别；允许人工补录 |
| 章节拆分不准 | 优先用文档原生结构；提供可视化编辑器人工调整 |
| LLM 幻觉（答疑/出题） | 强制 RAG + 引用；答案必须标注出处，无出处时声明"教材未覆盖" |
| 主观题阅卷不公 | 输出评分细则与得分点，用户可要求重新评阅 |
| 大文件处理卡顿 | 异步任务 + 增量解析；分块向量化 |
| 模型 Key 泄露 | 本地加密存储 + 系统钥匙串；不经过任何服务器 |
| 离线场景 | 可切换本地模型（Ollama），核心链路离线可用 |

## 9. 分期建议

- **P0（MVP）**：课程 + 教材导入 + 章节拆分 + 章节总结 + 模型管理（单模型）。
- **P1**：习题生成 + 题库 + 客观题测验 + 答疑（RAG）。
- **P2**：主观题 AI 阅卷、试卷导出、教案生成、多模型任务级选择。
- **P3**：错题本、知识点掌握度分析、学习计划。

## 10. 已确认决策（v0.1）

| 问题 | 决策 |
| --- | --- |
| 教材格式 | PDF 为主，也接受扫描图片（OCR 可选） |
| 共享方式 | 单机单用户，无多人/班级，AI 阅卷结果即最终结果 |
| 模型 | 默认云端 API（自带 Key），本地模型可选用于离线 |
| 移动端 | 暂不需要 |
| 作答方式 | 应用内作答为主；支持打印纸笔作答后手动录入答案再阅卷 |

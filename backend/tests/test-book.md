# 第1章 函数与极限

## 1.1 函数的概念

函数是数学中的基本概念。设 A、B 是非空的数集，如果按照某种确定的对应关系 f，使对于集合 A 中的任意一个数 x，在集合 B 中都有唯一确定的数 f(x) 和它对应，那么就称 f 为从集合 A 到集合 B 的一个函数。

## 1.2 数列的极限

按照某一法则，对每个正整数 n，对应一个实数 xₙ，这些实数按照下标从小到大排列的一列数叫做数列。数列极限的描述性定义：如果当 n 无限增大时，数列的一般项无限接近于某一确定的常数 a，那么常数 a 叫做数列的极限。

## 1.3 函数的极限（ε-δ 定义）

设函数 f(x) 在点 x₀ 的某一去心邻域内有定义。如果存在常数 A，对于任意给定的正数 ε（不论它多么小），总存在正数 δ，使得当 x 满足不等式 0 < |x − x₀| < δ 时，对应的函数值 f(x) 都满足不等式 |f(x) − A| < ε，那么常数 A 就叫做函数 f(x) 当 x → x₀ 时的极限，记作 lim(x→x₀) f(x) = A。

几何意义上，当 x 充分接近 x₀（但不等于 x₀）时，f(x) 充分接近 A。注意：极限存在与否与 f(x) 在 x₀ 处是否有定义无关。

## 1.4 连续与间断

设函数 y = f(x) 在点 x₀ 的某一邻域内有定义，如果 lim(x→x₀) f(x) = f(x₀)，则称 f(x) 在点 x₀ 连续。初等函数在其定义区间内都是连续的。

间断点分为两类：第一类间断点（左右极限都存在，包括可去间断点与跳跃间断点）与第二类间断点（左右极限至少一个不存在）。
